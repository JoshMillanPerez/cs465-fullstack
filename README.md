Architecture
Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA). We used a variety of frontend development techniques in my full stack project, including JavaScript and Express HTML, along with a single-page application. This specific website's frontend was mostly utilized in combination with HTML and JavaScript. For the websites' routes, controller modules, and models, we used JavaScript. The main application file, which is exported by the Express framework, also uses JavaScript.
Applications that run on a single page are also known as SPAs in this project. This page's primary function is to offer administrative tools for website management, whereas the Express pages relied on handlebar views through HTML pages.
Why did the backend use a NoSQL MongoDB database? We used the MongoDB database to develop a NoSQL backend. In order to store data like travel details and user login credentials, we used Mongoose within the Mongo database. It was convenient to utilize NoSQL as it does not need adherence to or reliance on a schema. However, as demonstrated by the implementation of the seedgooserc command, which provided us with the console page to build trips, it facilitates the storage and modification of data within the application.

Functionality
How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces? The primary distinction between JSON and JavaScript, in my opinion, is that JSON is excellent for data storage. JavaScript and JSON are related because JavaScript has the ability to contain functions, but JSON does not. The drawback of this is that, unlike JSON, which can be used in a wide variety of languages, JavaScript objects can only be utilized within JavaScript. Because JavaScript can transform JSON within the system, it works well with it. The data is then sent from the backend server to the frontend using the JSON format.
Provide instances in the full stack process when you refactored code to improve functionality and efficiencies, and name the benefits that come from reusable user interface (UI) components. Moving the HTML code to appropriate components that can be called from each page is one of the two primary instances of code restructuring for this project that increased functionality. In order to enhance functionality, the pages are changed to dynamically load data from the database. In order to call and show the file, we also made a header and footer file, which were made into partials for the handlebars view.
